# COMP4037 SurVis Literature Browser

This repository hosts a SurVis literature browser for COMP4037 Coursework 3.

Topic: **Robust and Privacy-Preserving 3D Medical Image Segmentation**

![Screenshot](/doc/survis.png)

The browser contains ten papers covering:

- benchmark datasets for brain tumour segmentation
- U-Net-derived 3D segmentation architectures
- automated biomedical segmentation pipelines
- privacy-preserving and federated learning
- adversarial robustness and medical image security
- survey/review literature
